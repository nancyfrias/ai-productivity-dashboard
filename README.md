# AI Productivity Dashboard

AI Productivity Dashboard is a modern task management dashboard built with Next.js, React, TypeScript, Tailwind CSS, and Recharts.

This project allows users to manage tasks, track progress, filter tasks by status, visualize productivity metrics, and switch between light and dark mode.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Change task status
- Filter tasks by status
- Dynamic productivity statistics
- Data persistence with localStorage
- Responsive design
- Dark mode
- Task analytics chart with Recharts

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Recharts
- Git
- GitHub
